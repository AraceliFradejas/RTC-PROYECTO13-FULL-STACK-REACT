Cada archivo conserva autor, enlace original y licencia en el manifiesto y la página de créditos. Las imágenes CC BY-SA y sus copias mantienen esa licencia; no se aplica a todo el código del proyecto. Las fotografías ilustran modelos y pueden mostrar otra versión o año. No acreditan unidades reales en las sedes.

Se han descartado trece candidatas, entre ellas una preparación policial, detalles sin el vehículo completo, duplicados visuales, interiores y variantes de carrocería que podían confundir. Las copias principales tienen 1920 px de ancho; la variante pequeña evita descargar ese tamaño en todas las tarjetas móviles.

La asignación estable prioriza fotografías del mismo modelo y alterna entre las disponibles para sus registros. Si falta una imagen de modelo, utiliza referencias de la marca. Las fotografías externas subidas a Cloudinary conservan prioridad. Tarjeta y ficha mantienen la misma asignación.

Para futuras búsquedas, el script de recolección descarga candidatas en una carpeta temporal y guarda su manifiesto; no modifica el catálogo automáticamente. Hay que revisar el encuadre, el modelo y la licencia antes de incorporar cada archivo. La asignación se regenera con el script de referencias.
